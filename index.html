VPS ALL BACKUP is a private utility for backing up data from a self-managed VPS to its owner's Google Drive account. Backup contents are encrypted locally using Restic before upload, with Rclone providing the Google Drive connection.

🔐

Encrypted first

Restic encrypts backed-up data on the VPS before it is sent to cloud storage.

☁️

Owner-controlled Drive

Google OAuth connects the backup utility to the owner's Google Drive account.

↩️

Recoverable history

Versioned snapshots support restoring data from earlier backup points.

Private use only. This website provides information about the utility. It does not accept file uploads, log users in, or expose backup data. Actual backups are performed on the owner's VPS, not through this website.
